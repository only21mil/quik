# Third-party asset provenance

## Launcher message glyph

The speech-bubble path in the QUIK Reactions launcher artwork is copied from the existing project asset `presentation/src/main/res/drawable/ic_message_black_24dp.xml`. That asset uses the path data of Google Material Icons' `message` glyph.

Google distributes Material Icons under the Apache License 2.0. A local copy of that license is at [third-party/licenses/material-icons-Apache-2.0.txt](third-party/licenses/material-icons-Apache-2.0.txt), and the upstream copy remains in the [Material Design Icons repository](https://github.com/google/material-design-icons/blob/master/LICENSE). The copied path remains subject to that license. The surrounding launcher composition, colors, and reaction badge are fork-specific work distributed under GPL-3.0-or-later. The project itself remains licensed under GPL-3.0-or-later.
