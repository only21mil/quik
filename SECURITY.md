# Security policy

## Supported versions

This fork has no supported release. Development branches and debug APKs are
experimental. They do not receive a compatibility or security support promise.

For a vulnerability in the unmodified upstream project, use the upstream
project's reporting route. This policy covers changes specific to
`only21mil/quik`.

## Report a vulnerability

Private vulnerability reporting has not been confirmed as enabled for this
fork. Disclosure therefore fails closed. Do not send vulnerability details to
an assumed advisory URL and do not post them in a public issue.

If the repository's Security page visibly offers GitHub's private
"Report a vulnerability" form, use that enabled form. Until then, a public
issue may ask the maintainers to enable or name a private reporting channel,
but it must contain no exploit details, reproduction steps, logs, or sensitive
data. Wait for a verified private channel before disclosing those details.

Include the affected commit, Android version, device model, steps to reproduce,
expected impact, and the smallest redacted evidence needed to confirm the
problem. Never send credentials, signing material, private messages, phone
numbers, contact databases, or full device logs.

The maintainers will assess the report and coordinate any public disclosure.
A report does not imply that a release, fix date, or supported build exists.

## Debug builds

Do not distribute a development APK as an official QUIK release. Before sharing
logs or screenshots from a debug build, remove message content, recipient data,
device identifiers, carrier details, and local filesystem paths that are not
needed to reproduce the issue.
